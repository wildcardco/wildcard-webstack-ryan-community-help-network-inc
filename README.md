# Community Help Network

Astro preview for Community Help Network in Crown Point, Indiana. Home of Buddy Bags.

The site starts from the Wild Card Astro template (Astro 7.4.10, Tailwind CSS 4.3.5, @astrojs/vue 7.1.4, and Vue 3.5.45). Interactive pieces are Vue single-file components. Styling uses a daisyUI theme mapped to the colors on the current site.

- `npm install`
- `npm run dev` starts the dev server
- `npm run build` runs `astro build --timings` and writes the timing summary to `build-timings.txt`

This preview sends `noindex`. Donations stay on Zeffy. Volunteer signup stays on Point. Nothing on this site takes a payment or stores a shopping list.
